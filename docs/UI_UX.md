# Hilmi OS UI & UX Specification

## Overview

Hilmi OS bukan website portofolio biasa.

Hilmi OS harus terasa seperti:

- Personal Operating System
- Digital Headquarters
- Professional Portfolio
- Knowledge Hub

User harus merasa:

"Ini adalah sistem yang benar-benar digunakan setiap hari."

Bukan sekadar website pajangan.

---

# Design Philosophy

## Minimal Premium

UI harus:

- Bersih
- Modern
- Elegan
- Cepat

Hindari:

- Terlalu banyak warna
- Terlalu banyak animasi
- Terlalu banyak elemen dekoratif

---

## Functional Beauty

Semua elemen visual harus memiliki tujuan.

Jika suatu elemen tidak membantu:

- Navigasi
- Pemahaman
- Konversi

maka jangan digunakan.

---

## Mobile First

Target utama:

Mobile.

Semua halaman harus didesain dari mobile terlebih dahulu.

Desktop adalah enhancement.

---

# Empty States

Must be meaningful.

Examples:

No tasks:

"Tidak ada tugas hari ini."

No goals:

"Mulai dengan membuat tujuan pertama."

---

# Loading States

Required:

Skeleton loading.

Avoid:

Spinners everywhere.

---

# Error States

Human language.

Avoid:

Technical messages.

Bad:

500 Internal Server Error

Good:

Terjadi kesalahan. Silakan coba lagi.

---

# Animation Principles

Animation should:

- Guide attention
- Improve understanding

Not:

- Distract

---

# Animation Usage

Allowed:

- Page transition
- Hover effect
- Card appearance
- Modal opening

Avoid:

- Heavy parallax
- Long loading animations

---

# Accessibility

Requirements:

- Keyboard support
- Focus states
- Sufficient contrast

---

# Responsive Design

Breakpoints:

Mobile
Tablet
Desktop

All pages must work properly.

---

# PWA UX

Must feel app-like.

Requirements:

- Install prompt
- Offline shell
- Mobile navigation

---

# CMS UX

Owner should manage content without coding.

CMS Modules:

- Blog
- Projects
- Timeline
- Achievements
- Gallery

---

# Final UX Principle

The system should feel powerful.

But never complicated.

The user should feel organized.

Not overwhelmed.
